Install

MANUAL INSTALL

1) You can download the Grade Setup Wizard plug-in from:
https://github.com/UNIMOODLE/moodle-gradereport_gradeconfigwizard
The plugin must be copied in:
[tudirectoriomoodle]/grade/report/gradeconfigwizard


2) You can download the Group filter Plain Text file add-on from:
https://github.com/UNIMOODLE/moodle-gradeexport_groupfilter_txt
The plugin must be copied in:
[tudirectoriomoodle]/grade/export/groupfilter_txt

3) You can download the Group filter XLS file add-in from:
https://github.com/UNIMOODLE/moodle-gradeexport_groupfilter_xls
The plugin must be copied in:
[tudirectoriomoodle]/grade/export/groupfilter_xls

UNINSTALL

1) Access the plugin uninstallation page:
Site Administration > Plugins > Plugins Overview. Find the plugin and click uninstall. Then, remove the gradereport_gradeconfigwizard plugin from the Moodle folder:
[tudirectoriomoodle]/grade/report/gradeconfigwizard

2) Access the plugin uninstallation page:
Site Administration > Plugins > Plugins Overview.
Find the plugin and click uninstall. Remove the gradeexport_groupfilter_txt plugin from the Moodle folder:
[tudirectoriomoodle]/grade/export/groupfilter_txt


3) Access the plugin uninstallation page:
Site Administration > Plugins > Plugins Overview.

Find the removed plugin and click uninstall. Remove the gradeexport_groupfilter_xls plugin from the Moodle folder:
[[tudirectoriomoodle]/grade/export/groupfilter_xls
