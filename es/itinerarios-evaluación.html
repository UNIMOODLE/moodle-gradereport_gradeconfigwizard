Editor de itinerarios de evaluación

Accede al asistente de configuración de calificaciones

Para acceder al asistente, primero deberás acceder a tu curso, y desde ahí ir al apartado de Calificaciones. Una vez dentro, tendrás que abrir el desplegable y clicar sobre el Asistente para configurar calificaciones.

Accede al editor de itinerarios de evaluación

El ‘Editor de itinerarios de evaluación’ facilita la creación de un Libro de calificaciones con varios itinerarios de evaluación para una misma asignatura. Para acceder al editor hay que ir a la parte superior del panel de control y hacer clic en la opción ‘Acceso al editor de itinerarios de evaluación’.

Creación de itinerarios

Dentro de un curso puede contener diferentes itinerarios evaluativos según proceda, entonces en este punto es dónde se pueden generar todos los itinerarios de evaluación del curso.

Cada itinerario está formado por diferentes categorías

Cada itinerario puede estar formado por diferentes categorías. En cada una de las categorías se puede establecer su ponderación global a nivel de dicha categoría. Luego, cada una de estas categorías se componen por elementos.

Elementos de cada una de las categorías

A cada categoría se pueden añadir tantos elementos como se deseen. Para cada elemento se deberá elegir que ponderación tiene dentro de dicha categoría.

Una vez definidos todos los elementos, se podrá guardar y salir.

Sincronización con el Libro de calificaciones

Todos los cambios que realices quedan guardados en el Libro de calificaciones de Moodle, donde también puedes hacer los ajustes que quieras en caso de necesitarlo.
