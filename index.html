Gradebook+

Plugins for improving Moodle gradebook functionality

Community project

In the framework of the European NextGeneration funds with the UNIDIGITAL programme, the universities of Valladolid, Complutense de Madrid, País Vasco/EHU, León, Salamanca, Illes Balears, Valencia, Rey Juan Carlos, La Laguna, Zaragoza, Málaga, Córdoba, Extremadura, Vigo, Las Palmas and Burgos created in October 2022 an inter-university group to develop new tools to improve virtual campuses based on Moodle.

What is GRADEBOOK+?

Gradebook+ is a set of plugins for Moodle, the world's most popular open source learning management system (LMS).

For many users, creating an assessment scheme is a complex and counter-intuitive task. Gradebook+ extends and enhances the current gradebook configuration interface making the task of grade management simpler.

Why use it?

Fully integrated with the native Moodle gradebook, Gradebook+ includes its own Dashboard that allows you to perform the most common actions in an agile way. Actions such as creating an assessment category or an item are done in a single click. Reordering table elements is now possible using drag and drop. You can also exclude any element from the final calculation using the Deactivate function. In addition the Dashboard gives access to an improved formula editor where it is no longer necessary to know the syntax when writing a custom calculation.

Gradebook+ has two grade export plugins with information about the group in which the student is enrolled. This feature has been added to Moodle core as of version 4.3.
You will find an editor for two of the most common assessment schemes among teachers: weighted assessments and assessment pathways.

Free and open source: Gradebook+ is a set of plugins for Moodle, which is a free and open source LMS. This means that you can use Gradebook+ without any cost or license fee, and you can also modify, improve and share it with others, thanks to the UNIMOODLE University Consortium, which created and maintains Gradebook+.

Who is the target audience?

Gradebook+ is focused on teachers using the Moodle gradebook. Gradebook+ is compatible with Moodle 4.1 and higher, and is fully integrated into your native gradebook system.

Designed for Moodle

Gradebook+ has been developed and integrated as a plugin for Moodle, the world's largest e-learning platform.

It fully integrates with the native gradebook and complements it, streamlining the most common tasks and facilitating its management.

Integrated into your Moodle site

Gradebook+ integrates into the platform your teachers know best.

Assistant for evaluation schemes

Gradebook+ provides you with an editor for two of the most common assessment schemes among teachers: weighted assessments and assessment pathways.
You will be able to quickly and easily create a structure of categories and assessment items with their respective weightings and remediation items. You will also be able to create assessment pathways according to the student's learning path.

Dahsboard+

Gradebook+ offers you its own dashboard where you can quickly and intuitively access the most common actions when managing the gradebook of a course.
